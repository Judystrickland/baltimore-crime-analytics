# Baltimore Crime Pattern Analysis and Forecasting Dashboard

## Project Objective
This project analyzes Baltimore crime patterns using public crime data. The goal is to identify crime trends, geographic hotspots, and forecast future crime patterns.

## Tools Used
- SQL
- Python
- Tableau
- GitHub

## Key Analysis
- Crime trend analysis
- Crime type comparison
- District-level crime analysis
- Geographic hotspot mapping
- 12-month crime forecasting

## Data Source
Baltimore Police Department / Open Baltimore crime data.

## Limitations
The data is preliminary and subject to change. It should not be compared with FBI UCR statistics. BPD has also noted reporting-system issues affecting Part 1 crime data after May 2021.
